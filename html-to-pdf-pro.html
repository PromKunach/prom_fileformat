Preview

The exact final pagination is controlled by the browser print engine. Use Print / Save as PDF for the highest fidelity.

Font reliability

Best: embed fonts with @font-face using a data: URL. Remote fonts can fail because of CORS, network access, or loading timing. A font-family name alone does not include the font.

Export advice

Print / Save as PDF uses the browser's native renderer and is recommended for custom fonts, A4 CSS, page breaks, SVG and complex layouts.

Quick PDF rasterizes the page and is useful when you want a direct download, but it may differ from print output.
